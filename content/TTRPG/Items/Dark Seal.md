Epic
*\[attune] (ring) (unique)*

#### Description
Whenever the user of this item kills a worthy creature this item gains two *Sorcery Points*.

If this creature dies at the hands of another creature, if the user of this item has dealt damage to the creature within the last round, the item gains one *Sorcery Point* instead.

This item can hold no more than ten *Sorcery Points*. Additionally, any time the user of this item drops to 0hp, five *Sorcery Points* are lost (the count will not drop below 0).

**Empowered Spells.** When you cast a spell that consumes resources, you add **+1 to the damage** per *Sorcery Point* within the item.

**Awaken.** While this item has ten *Sorcery Points*, if the creature wearing this ring kills a Lich, this item transforms into [[Hayun's Dark Pact]], retaining its sorcery stacks.
