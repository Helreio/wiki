#### Description
The dice looks worn out from being used a lot. 
You can roll the dice (d6) only once per day for a reward.  

|     |                 |                                                                |
| --- | --------------- | -------------------------------------------------------------- |
| 1   | Enfeeblement    | -2 Str Score for 10 minutes                                    |
| 2   | Fortune’s Favor | Gain *Advantage* on one roll, you can use within the next hour |
| 3   | Blackened Curse | You are *[[Conditions#Blinded\|Blinded]]* for 1 hour           |
| 4   | Vitality        | Heal for 1d4 hit points                                        |
| 5   | Ill Omen        | Cursed for 1 hour; all healing you receive is halved           |
| 6   | Stroke of Luck  | You find 1d4 gold coins nearby                                 |
|     |                 |                                                                |

*{“Today's my lucky day.” - Ves, the swamp elf}*
